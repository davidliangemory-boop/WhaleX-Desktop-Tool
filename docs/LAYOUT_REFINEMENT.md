# WhaleX 页面分级与记录工具

保留现有星海动效和鲸鱼主视觉，仅优化页面组件与文字层级。首页展示最近三条记录；本周新增、待整理、今日回顾三项全为零时统计行隐藏。更多内容通过导航、记录菜单、详情和设置弹窗展开。

## 主视觉锁定

基准提交：9952432190004e940daa848a41e2f2ede74d070f。

web/scene.js、web/scene.css、web/styles.css、现有鲸鱼和星海素材、品牌图标及 hero 标记保持原样。新样式集中于 workspace.css，新工具集中于 workspace.js，没有调用场景 API 或覆盖主视觉几何样式。月亮、地球、鲸鱼与光轨继续由原有代码和素材呈现。

tests/scene-lock.json 记录文件 SHA-256、hero 标记及六种窗口尺寸的坐标；Node 测试阻止主视觉文件变化，浏览器测试验证位置。可设置 WHALEX_REFERENCE_WEB 指向原版 web 目录，对比相同静止帧的星海与鲸鱼 canvas 像素。

### 2026-09-30 用户确认的高清渲染例外

用户查看手机 1×/3× 实际网页对比图后，批准应用高清鲸鱼渲染。仅更新 scene.js 的鲸鱼画布与变形缓冲区像素密度，并更新上述锁定清单中的该文件哈希；鲸鱼与星海素材、CSS、HTML、位置、缩放、游动、光轨和背景绘制公式保持不变。全屏背景继续采用原像素预算，鲸鱼画布最高 3×、约 180 万像素，原性能降级机制启用时降至最高 1.5×。这不是替换鲸鱼图片或改变动画。

参考像素对比现在严格保持星海、背景及主视觉几何不变；鲸鱼画布抗锯齿是本次批准的例外。新增手机 1×/2×/3×、横屏像素预算、原动画及减少动态偏好测试。桌面浏览器模拟手机不等同于真机 Safari 性能验收。

index.html 仅为 scene.js 添加版本查询参数，使新版页面不会复用旧渲染脚本缓存；页面布局、内容和 hero 标记不变。

### 2026-09-30 首页视觉收敛（不修改背景）

本次视觉优化基准为高清版本 b39932da6a282d22291bf165ccca562c0d0c312f。所有背景、鲸鱼、月亮、地球、光轨素材与渲染代码保持该版本原样；scene.js、scene.css、styles.css 和素材文件哈希未变。之前批准的高清渲染不再是本次像素对比的例外：当前测试对星海与鲸鱼静止帧均要求逐像素一致。

新样式集中在 refinement.css。只将 Hero 文字缩为 75%、透明度设为 0.68，并删除重复描述；图片、画布、Hero 容器位置及尺寸不变。锁定清单记录此次文字标记变更的明确例外。删除重复侧栏鲸鱼装饰、重叠手写文案；便签统一为深色玻璃，取消便签自身纸张漂浮，不触碰背景动效。

零计数徽章不显示；全零统计行隐藏；任务、回顾无数据时变为 48px 单行；最近记录保留唯一空态及记录按钮。隐藏统计行时，知识概览仍可由记录面板工具栏打开，AI 提炼仍可由导航和移动端菜单打开。独立便签窗口及编辑弹窗采用相同玻璃样式。数据计算、持久化、同步与业务动作保持不变。

### 2026-09-30 实底框架与可收起抽屉

替代上述玻璃主面板方案。基准提交 9f9430a43829ad03edfb11b6a6d4081df4f3a990；新增 frame.css / frame.js 只管理 UI，原场景文件、素材、容器尺寸和画布位置保持不变，也不增加背景遮罩。Hero 中央文字按用户要求移除，WhaleX 字标只留侧栏。

固定实底侧栏、短搜索和状态胶囊围住舞台；最近记录固定于底部，桌面约占 26% 视口。原有任务、回顾、统计和悬浮便签入口归入底栏“更多”，其他导航与功能保留。记录抽屉默认隐藏且 inert；桌面在原右侧空位展开，手机从鲸画布下方打开，不移动鲸或遮盖鲸的画布。输入抽屉为非模态：关闭按钮与 Escape 收起后恢复焦点，草稿保留。过渡仅 8px / 160ms，小菜单允许 5px 模糊，主面板均实底。

编辑、筛选、AI 提炼、设置等既有弹窗也沿同一右侧边界排列，手机在鲸画布下方展开；弹窗内容滚动，不覆盖鲸的画布，也不加背景遮罩。

快捷键冲突按“不改现有快捷键”处理：Ctrl/⌘ K 仍聚焦搜索；Ctrl/⌘ Enter 在非输入状态打开记录，在记录表单内继续保存；Ctrl Shift Space 原悬浮窗口逻辑不变。侧栏“快速记录”现在打开抽屉，原悬浮窗口仍有“更多 → 悬浮便签”和记录菜单入口。输入、归档建议、保存、数据、同步及外部连接逻辑不变。

## 功能入口

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| 快速记录 | 右侧便签、快速记录按钮 | 只填内容即可保存。标题、资料库、类型和标签折叠；新记录可进入未分类。保存后可撤销并回到草稿。 |
| 多级标签 | 导航“分级标签” | 标签父级包含子级；便签支持已有标签建议。资料库负责项目归属，标签连接跨库主题。 |
| 每日回顾 | 回顾页签、导航、右侧回顾入口 | 按范围、最小记录年龄和每天数量选出旧记录。选择固定于当天，已回顾状态保留在本机。 |
| 随机回顾 | 记录区底部 | 从已有记录中随机打开一条；不会生成示例数据。 |
| 详情与关联 | 点击记录标题 | 查看正文、相关标签/资料库记录、引用、反向链接和批注；批注与引用随记录同步。 |
| 历史版本 | 记录菜单、详情“版本” | 本机保留最近 20 次正文、标签、归属、类型和引用变化；可对照、标记好版本和恢复。恢复保留当前收藏及批注，避免覆盖其他窗口的新编辑。 |
| AI 提炼 | 导航或概览栏、记录菜单 | 按资料库、标签、日期和具体记录选来源，先预览、再保存新记录与来源引用。支持 Prompt、摘要、问题清单、工作流。 |
| 工作流 | 导航、工作流视图“新建工作流” | 保存输入目标和有序步骤，作为可复用的工作流记录。 |
| 搜索与筛选 | 搜索框、“筛选”弹窗 | 保留全文搜索；本地识别“本周的合同 Prompt”等时间、类型及标签表达，另可设置日期与资料库范围。 |
| 知识概览 | 记录工具栏、概览栏、移动端菜单 | 真实记录热力图和标签共同出现的连接图；点击日期或主题可筛选记录。 |
| 模型、flomo | 设置与连接中的折叠区 | 由用户填写 HTTPS 模型接口、模型名与密钥，或 flomo 记录 API。配置本身不发送数据。 |
| 移动端二级导航 | 顶部“更多功能”菜单 | 提供资料库、标签、收藏、归档、提炼、工作流、概览及导出入口。 |

## 数据与连接边界

- 原有 IndexedDB 数据和 Supabase 账号隔离继续使用；没有改数据库结构、登录接口、RLS 或 sync.js。
- 引用与批注在记录 payload 中保存。导入备份会为全部记录创建新 ID，并把内部引用指向导入副本，不覆盖原记录。
- 历史版本与回顾设置/进度按账号保存在本机；版本不随云端同步，也不包含在常规记录备份中。
- 未配置模型时，“AI 提炼”使用原文摘录与本地模板，明确标为本地结构化草稿。只有用户选择外部模型并点击生成，才发送勾选的记录及补充目标。
- 模型与 flomo 的配置仅存于当前标签页的 sessionStorage，按账号区分；不会进入笔记、备份、云端或仓库。推荐可信模型代理。接口必须允许网页跨域调用。
- flomo 功能是手动单向发送，要求用户提供记录 API；没有宣称双向同步或 MCP 读取。请求超时后应先确认 flomo 是否已保存，再决定重试。
