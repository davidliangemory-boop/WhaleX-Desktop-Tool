# WhaleX Luminous：参考图视觉与动效实现

2026-09-30：在现有 Observatory 主题上完成参考图视觉升级。页面仍使用同一份 IndexedDB 数据和同步代码。

## 视觉层

- 独立透明鲸鱼：`web/assets/whale-luminous.webp`，1400px 宽，保留真正的 alpha 边缘。
- 星空环境：`web/assets/cosmic-landscape.webp`，独立于文字、表单和鲸鱼。两个 WebP 素材合计约 548 KB。
- 由用户提供的概念图指导，使用内置 imagegen 生成素材；未把整张界面截图作为网页背景，也未烘焙 UI 文字。
- 导航、功能卡片、精选空间、今日任务和便签都是可操作的 DOM。精选空间数量来自当前账号实际记录，不植入示例数据。
- 主页面和独立便签共享暖白纸面、紫色胶带、边缘光与蓝色保存按钮。

## 生成提示词摘要

鲸鱼：从参考图提取发光蓝鲸的视觉语言；朝右略向上游动，完整尾部与胸鳍，钴蓝身体、星点纹理、青色轮廓光；透明背景，无文字、星球、轨道和 UI。

环境：参考图的 16:9 深蓝宇宙环境；发光星球、巨大的弧形星球地平线、细星点、下缘冰蓝山脊；两侧和下半部留出可读空间；无鲸鱼、文字、卡片和 UI。

## 运动与性能

`scene.js` 使用预渲染纹理和 Canvas。鲸鱼轻微游动、尾部形变、星尘闪烁、银河缓慢旋转与轨道光点独立运动。卡片根据指针位置显示柔和高光和很小的倾斜，点击有短促反馈，便签轻微漂浮。

- 保留沉浸、轻柔、静止三档，并保存用户选择。
- 输入时减弱背景亮度与速度，停止便签漂浮。
- 自动尊重系统减少动态设置；隐藏页面和 bfcache 离开时暂停，恢复时继续。
- 装饰层不截获鼠标；DPR 最高 1.5；较慢设备自动降为 30fps。
- 素材、脚本同源，不增加外部 CDN 或分析请求。

## 验收

现有 `npm run check`、`npm test`、`tests/browser_smoke.py` 与 `tests/scene_browser.py` 覆盖保存、草稿、归档、账号隔离、模拟同步、动效暂停、系统减少动态和五种屏幕宽度。新增精选空间数量/筛选、首页清除筛选、新增任务和完成进度检查。

浏览器验收使用 Chromium；同步传输使用现有 mock。此视觉修改不改变后端数据库、账号配置和同步算法。真实云端同步是否已配置，以用户自己的连接状态为准。
